# Live Feed Application v12

High-performance stock market live feed with Excel integration.

## Features
- **Real-time tick data** from Angel Broking
- **Excel integration** with live updates
- **Technical indicators** (SMA, RSI, VWAP, Support/Resistance)
- **Alert system** for price movements and patterns
- **Token backup** and restore functionality
- **Rate limiting** and circuit breaker for API safety
- **Multi-threaded** processing for high performance
- **Auto-backup** during market hours
